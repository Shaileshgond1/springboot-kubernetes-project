1. Enable Ingress in Minikube
On your EC2:

minikube addons enable ingress

Then check: kubectl get pods -n ingress-nginx

 ingressclass : networking.k8s.io/v1

vi ingress.yml

apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: api-ingress
spec:
  ingressClassName: nginx
  rules:
    - http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: service2
                port:
                  number: 8080

kubectl apply -f ingress.yml

enable ip forwarding on ec2 : sudo sysctl -w net.ipv4.ip_forward=1

sudo iptables -t nat -A PREROUTING -i enp39s0 -p tcp --dport 8080 -j DNAT --to-destination 192.168.49.2:32021

meaning :
Incoming EC2 :8080
        ↓
change destination to
        ↓
192.168.49.2:32021

Then add masquerading for the return traffic:
sudo iptables -t nat -A POSTROUTING -p tcp -d 192.168.49.2 --dport 32021 -j MASQUERADE



3. Check that the rules exist


sudo iptables -t nat -L -n -v
